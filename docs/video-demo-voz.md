# Video demo: texto para grabar la voz

Cómo leerlo:
- `/` = pausa corta (respirar). `//` = pausa larga (2 segundos, mientras pasa algo en pantalla).
- **NEGRITA** = apoyá la voz en esa palabra.
- (entre paréntesis) = cómo decir el término en inglés, sin leerlo.
- Hablá un poco más lento de lo normal y sonriendo: se nota en la voz. Grabá cada escena en un archivo aparte y dejá 1 segundo de silencio al principio y al final.

Cómo decir los nombres técnicos:

| Escrito | Decilo |
|---|---|
| Spotter | espóter |
| Next.js | néxt yei-és |
| FastAPI | fást ei-pi-ái |
| PostgreSQL | póstgres ku-él (o "póstgres" a secas) |
| Cloudflare | cláud-fler |
| Workers AI | uórkers ei-ái |
| Vercel | vercél |
| Neon | níon |
| IA | i-á |

## Escena 0 · Apertura (hay que dejar unos 15 s)

Este es **Spotter** (espóter), / una app de entrenamiento con **inteligencia artificial**. //
La idea es simple: / vos **anotás** lo que entrenás / y, al cerrar la semana, / la IA **compara** lo que tocaba / con lo que hiciste **de verdad** / y te propone la **semana siguiente**.

## Escena 1 · Armar la rutina (≈ 48 s)

Para empezar elijo el **objetivo**, / mi **nivel**, / cuántos **días** puedo entrenar / y cómo quiero **repartir** el cuerpo. //
La IA arma la rutina, / pero **no inventa**: / elige solo de un catálogo **cerrado** de ciento veintisiete ejercicios, / y el **código** comprueba reglas de entrenamiento **con fuente**, / como el volumen mínimo por músculo. //
Cada ejercicio explica **cómo se hace** / y **por qué está**. //
Si uno no me gusta, / lo cambio por otro del catálogo. //
Nada se guarda hasta que yo **acepto**: / la IA **propone** / y yo **decido**.

## Escena 2 · Entrenar un día (≈ 51 s)

En el gimnasio, / la app me muestra **un ejercicio a la vez**. //
Toco "**Serie hecha**" / y queda registrado lo **planificado**; / si levanté **otro peso** / o hice **menos repeticiones**, / lo cambio acá. //
El reloj de descanso arranca **cuando yo quiero**. //
Lo **planificado** y lo **real** se guardan por separado, / y esa **diferencia** / es lo que después **analiza la IA**.

## Escena 3 · Cerrar la semana (≈ 49 s)

Al final de la semana / la cierro con **un botón** / y le cuento **cómo me sentí**. //
La IA lee ejercicio por ejercicio / qué **superé**, / qué **cumplí** / y dónde **no llegué**. //
Si superé, **sube** el peso; / si no llegué y conté que estaba **cansado**, / **baja un escalón**, / y ese peso lo calcula el **código**, / no la IA. //
Antes de aceptar / veo **exactamente** qué cambió / respecto de la semana pasada.

## Escena 4 · Progreso (≈ 52 s)

(Las pantallas van pasando solas; hablá al ritmo de ellas.)

En **Progreso** / veo el resumen de cada **semana**. // (Resúmenes)
Veo qué **músculos** trabajé / en el mapa del cuerpo, // (Mapa y Radar)
cómo **evolucionó** cada ejercicio, // (Evolución)
mi **peso**, // (Cuerpo y peso)
y los **días que entrené**. // (Calendario)

## Escena 5 · Cierre técnico (≈ 13 s; la placa va mostrando cada tecnología)

Por dentro: / el frontend es **Next.js** (néxt yei-és), / el backend **FastAPI** (fást ei-pi-ái) con **PostgreSQL**, / y la IA es **Cloudflare Workers AI** (cláud-fler uórkers ei-ái), / en su plan **gratuito**, / con topes que el código aplica **antes de cada llamada** / para que nunca genere **costo**. //
Está publicada en **Vercel** (vercél) / y se puede **instalar en el teléfono**. //
**Gracias.**
